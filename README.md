# hh-homework-ts

## Домашнее задание по TypeScript.

В рамках задания необходимо было переписать задачи с JavaScript на TypeScript с использованием типизации, generic-типов и проверки типов во время компиляции.

### Задания
1. `task1-promise-all.ts` — реализована собственная версия Promise.all
    - Принимает массив промисов или значений
    - Возвращает Promise с массивом результатов
    - Сохраняет порядок результатов
    - Отклоняется при первой ошибке
2. `task2-delay.ts` — реализована функция delay(ms)
    - Возвращает Promise
    - Промис выполняется через ms миллисекунд
3. `task3-memoize.ts` — реализована функция memoize(fn)
    - Кэширует результат функции
    - Аргументы функции — только string или number
    - Используется Map для хранения кэша
    - Сохранены типы аргументов и возвращаемого значения функции
4. `task4-typed-object.ts` — реализована функция typedObject(schema)
    - Создает объект на основе схемы типов
    - При присваивании проверяет тип значения
    - При несоответствии типа выбрасывает ошибку
    - Типы свойств выводятся автоматически из схемы (TypeScript)
